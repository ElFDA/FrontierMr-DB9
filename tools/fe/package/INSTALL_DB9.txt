FRONTIER FOR MISTER-DB9 - INSTALLATION
======================================

Package date: @BUILD_DATE@.
@FLAVOUR@

This is a TEST version for a MiSTer that uses the MiSTer-DB9 fork. Saturn
pads do not work (DB9 enables them
with a signed db9pro.key that builds made outside DB9's own CI cannot
validate; DB9MD and DB15 do not need it). Please tell us what happens.

1. Copy the CONTENTS of the SD folder to the root of your MiSTer SD card.
   Replace the package files if you are upgrading an older installation.
2. On MiSTer, select F12 -> Scripts -> frontier_install.
   It saves the MiSTer you have now (DB9's), keeps your settings and protects
   Frontier from updates. MiSTer then reboots.
3. With a CRT on the VGA output of the I/O board, also run
   F12 -> Scripts -> frontier_crt (it is also in Frontier Settings -> CRT
   output). Run it again to turn it off.

Use update_all with the DB9 database as usual afterwards. If an update puts
DB9's MiSTer back, Frontier's returns at the next reboot (frontier/guard.sh).
Frontier has its own database for update_all (frontiermr_db9, added by
frontier_install as downloader_frontiermr_db9.ini in the root of the SD), so
update_all updates Frontier too (your settings, favorites, lists and media are
kept). Without this package: copy
https://github.com/ElFDA/FrontierMr-DB9/releases/latest/download/downloader_frontiermr_db9.ini
to the root of the SD, run update_all, then F12 -> Scripts -> frontier_install.

SWITCH THE INTERFACE ON OR OFF
  Run F12 -> Scripts -> frontier_on_off. MiSTer stays Frontier's.

BACK TO YOUR PREVIOUS MiSTer
  Run F12 -> Scripts -> frontier_uninstall. It stops the protection,
  removes Frontier from the updates and puts back the MiSTer you had before
  (MiSTer.orig); without it the next update_all brings DB9's MiSTer.
  Frontier's media and settings are kept for a later installation.

IF INSTALLATION STOPS
  Do not run another updater during installation. If update protection
  cannot be configured, installation stops before replacing MiSTer.
  Send the error to the package maintainer; details are recorded in
  frontier/update_protection.log.

FULL GUIDE
  See frontier/README.txt on the SD after installation (UPDATES section).

Problems and reports: https://github.com/ElFDA/FrontierMr-DB9/issues
